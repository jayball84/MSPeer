# MSPeer

A peer group for MSP leaders. Founders and C-suite from £1m+ managed service providers — capped at twelve seats, hosted around rotating boardrooms.

Hosted by [Jay Ball](https://flotek.io) (Flotek Group) and Danny Mills (Everything Tech).

## The site

`index.html` is a single self-contained page — no build step, no dependencies beyond Google Fonts. Deploy anywhere that serves static files (Cloudflare Pages, GitHub Pages, Vercel, Netlify).

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
